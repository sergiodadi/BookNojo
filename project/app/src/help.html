📚 BookNojo

Guide d'utilisation

User guide

📂 Ouvrir une collection

Le bouton « 📂 Ouvrir une collection… » dans l'en-tête (identique à Fichier → Open Collection…) ouvre le sélecteur natif macOS pour choisir une collection — un dossier .bkcp (Book Collector) ou .col (BookNojo).

  • Le choix est mémorisé : au lancement suivant, BookNojo rouvre la même collection sans rien demander.
  • Une collection .bkcp d'une version de Book Collector différente de celle visée (20.3.1) est refusée avec un message clair, plutôt qu'un plantage.
  • Au tout premier lancement, BookNojo ouvre une collection d'exemple entièrement fictive (10 livres inventés) — il y a toujours quelque chose à voir, sans jamais exposer de vraies données par défaut.

📚 Parcourir la bibliothèque

Trois zones redimensionnables à la souris : le regroupement à gauche, la liste des livres en haut à droite, la fiche détail en bas à droite.

  • Regroupement par Auteur (par défaut), Genre, Éditeur, Format, Langue ou Pays, avec une barre A→Z.
  • Liste : recherche texte, tri, pagination, bascule liste/grille (vignettes de couverture).
  • Sous-collections multiples dans un même fichier — des onglets permettent de passer de l'une à l'autre.
  • Statistiques : vue agrégée par genre/format/langue/ éditeur/décennie. Le compteur « N sans couverture » est cliquable et déroule une liste de livres ; cliquer sur l'un d'eux ouvre un sélecteur de fichier pour lui poser une couverture immédiatement.
  • Fiche détail : couverture, titre/auteurs/éditeur, puis (quand renseignés) Détails produit, Édition originale, Détails personnels, Crédits, Personnages, Contenus, Liens, Intrigue et Notes.

✏️ Ajouter, modifier, supprimer un livre

  • Ajouter : un formulaire en sous-onglets, avec auto-complétion. Avant toute écriture, une boîte de confirmation liste chaque valeur qui serait créée pour la première fois (badge « nouveau ») — pour repérer une faute de frappe avant qu'elle devienne permanente.
  • Une couverture peut aussi être choisie directement dans le formulaire d'ajout (bouton « Choisir une image… », optionnel). Si l'ajout réussit mais pas la couverture, le livre est quand même ajouté — rattrapable ensuite.
  • Recherche en ligne : bascule « ✍️ Manuellement » / « 🔍 Recherche en ligne » en haut du formulaire. Un seul champ (titre, auteur ou ISBN) interroge 3 sources gratuites en même temps (Open Library, Google Books, BnF) ; choisir un résultat pré-remplit le formulaire manuel (et télécharge la couverture si disponible) — rien n'est écrit avant la confirmation habituelle.
  • Modifier : depuis la fiche détail, même formulaire pré-rempli, même étape de confirmation.
  • Supprimer : depuis la fiche détail, après confirmation. Seules les lignes propres à ce livre sont retirées — une valeur partagée n'est jamais supprimée.
  • Après chaque action, la bibliothèque se recharge automatiquement.

🌐 Interface bilingue

Le sélecteur FR / EN dans l'en-tête bascule toute l'interface — regroupement, liste, fiche détail, statistiques, formulaires. Le choix est mémorisé d'une session à l'autre.

Les messages renvoyés par l'application elle-même après une action (confirmations, erreurs) restent en français quelle que soit la langue choisie, pour l'instant.

🛡️ Sécurité des données

Toute écriture (ajout, modification, suppression, couverture) est précédée d'une sauvegarde horodatée du fichier.

BookNojo peut ouvrir la vraie collection Book Collector en lecture seule pour la consulter, mais aucune écriture n'a d'exception possible pour elle depuis l'application — et toute écriture est refusée si Book Collector est lancé en même temps, pour éviter un conflit.

🚧 Pas encore disponible

  • Recherche en ligne pour pré-remplir une fiche à partir d'un ISBN (OpenLibrary/Google Books/BnF).
  • Application pas encore signée/notariée par un compte développeur Apple — sans conséquence pour un usage personnel.

🔧 Pour aller plus loin

Pour un usage quotidien, l'application seule suffit. Pour les outils en ligne de commande (bc_export/ bc_add — export CSV/JSON/HTML, scripts, transition depuis Book Collector), voir CLI.fr.md dans le dépôt. CHANGELOG.fr.md garde l'historique des versions publiées.

📂 Opening a collection

The "📂 Open Collection…" button in the header (same as File → Open Collection…) opens the native macOS file picker to choose a collection — a .bkcp folder (Book Collector) or .col (BookNojo).

  • The choice is remembered: on the next launch, BookNojo reopens the same collection without asking anything.
  • A .bkcp collection from a different Book Collector version than the one targeted (20.3.1) is rejected with a clear message, rather than a crash.
  • On the very first launch, BookNojo opens an entirely fictional sample collection (10 invented books) — there's always something to see, without ever exposing real data by default.

📚 Browsing the library

Three zones, resizable with the mouse: grouping on the left, the book list at top right, the detail card at bottom right.

  • Grouping by Author (default), Genre, Publisher, Format, Language or Country, with an A→Z bar.
  • List: text search, sort, pagination, list/grid toggle (cover thumbnails).
  • Multiple sub-collections in a single file — tabs switch between them.
  • Statistics: an aggregated view by genre/format/ language/publisher/decade. The "N with no cover" count is clickable and expands a book list; clicking one opens a file picker to set its cover right away.
  • Detail card: cover, title/authors/publisher, then (when filled in) Product Details, Original Edition, Personal Details, Credits, Characters, Contents, Links, Plot and Notes.

✏️ Adding, editing, deleting a book

  • Add: a form organized into sub-tabs, with autocomplete. Before writing anything, a confirmation box lists every value that would be created for the first time (a "new" badge) — to catch a typo before it becomes permanent.
  • A cover can also be picked right from the Add-book form (optional "Choose an image…" button). If the add succeeds but not the cover, the book is still added — fixable afterward.
  • Online search: a "✍️ Manually" / "🔍 Online search" toggle at the top of the form. One field (title, author, or ISBN) queries 3 free sources at once (Open Library, Google Books, BnF); picking a result pre-fills the manual form (and downloads the cover if available) — nothing is written before the usual confirmation.
  • Edit: from the detail card, the same pre-filled form, same confirmation step.
  • Delete: from the detail card, after confirmation. Only rows specific to that book are removed — a shared value is never deleted.
  • The library reloads automatically after every action.

🌐 Bilingual interface

The FR / EN selector in the header switches the whole interface — grouping, list, detail card, statistics, forms. The choice is remembered from one session to the next.

Messages returned by the application itself after an action (confirmations, errors) stay in French regardless of the chosen language, for now.

🛡️ Data safety

Every write (add, edit, delete, cover) is preceded by a timestamped backup of the file.

BookNojo can open the real Book Collector collection in read-only mode to browse it, but none of the write actions have any exception for it from the application — and every write is refused if Book Collector is running at the same time, to avoid a conflict.

🚧 Not available yet

  • Online lookup to pre-fill a record from an ISBN (OpenLibrary/Google Books/BnF).
  • Not yet code-signed/notarized with an Apple developer account — no consequence for personal use.

🔧 Going further

For everyday use, the application alone is enough. For the command-line tools (bc_export/bc_add — CSV/JSON/HTML export, scripts, transition away from Book Collector), see CLI.md in the repository. CHANGELOG.md keeps the history of published versions.
